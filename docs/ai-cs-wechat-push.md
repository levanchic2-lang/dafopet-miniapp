# 小程序客服消息推送

把微信小程序自带的客服消息接到医院的 AI 客服。客户从「联系客服」进来后，可以查空档、预约、改期和取消。提交之前一定会先把门店、项目、宠物、日期和时间发回去，等客户回复确认。

默认关闭。关闭时这个地址仍然验签，并且把消息转给微信里原来的客服工具，不会调用 AI。

## Chi 要在公众平台填的内容

小程序 AppId：`wxd1918a78b050310d`。

1. 打开 [微信公众平台](https://mp.weixin.qq.com)，用这个小程序的管理员扫码登录。
2. 进入 **开发管理**，再进入 **开发设置**（有的账号直接能看到 **消息推送**）。
3. 找到 **消息推送**，点启用或修改。
4. 按下表填写，然后点提交。微信会立刻发一条 GET 来验地址，验不过就保存失败。

| 项 | 填什么 |
| --- | --- |
| URL | `https://dafopet.com/api/wechat/cs-push` |
| Token | 自己定一串，只含字母和数字。必须和服务器 `WECHAT_CS_TOKEN` 完全一致 |
| EncodingAESKey | 点随机生成。43 位。必须和服务器 `WECHAT_CS_AES_KEY` 完全一致 |
| 消息加密方式 | 选 **安全模式**。明文模式也能用，兼容模式会按密文解密 |
| 数据格式 | **JSON** 或 **XML** 都可以 |

服务器上的 `WECHAT_APPID` 和 `WECHAT_APPSECRET` 继续用现在 code2session 和 access_token 那一组，不要另做一套。客服回复走 `customerServiceMessage.send`，用的就是这份 access_token 缓存。

提交时如果提示校验失败：看 Token 是否一致、地址是不是 `https://dafopet.com/api/wechat/cs-push`、服务是否已重启。安全模式还要核对 EncodingAESKey 和 AppId。

## 环境变量

写在服务器 `.env`，改完重启。不要写进小程序，不要提交进仓库。

| 变量 | 作用 |
| --- | --- |
| `WECHAT_CS_TOKEN` | 和公众平台 Token 一致。没配时地址验签会失败 |
| `WECHAT_CS_AES_KEY` | 和 EncodingAESKey 一致。安全模式必填 |
| `WECHAT_APPID` / `WECHAT_APPSECRET` | 现有小程序密钥。安全模式用 AppId 核对密文，发消息用它换 access_token |
| `AI_CS_ENABLED` | `1` 才调用 AI。不写或 `0` 时只验签并把消息转给微信客服，不回复 AI |
| `AI_CS_TEST_OPENIDS` | 逗号分隔的 openid。写了之后，只有这些微信会收到 AI；其他人仍转给微信客服 |
| `DEEPSEEK_API_KEY` 等 | 沿用 B 超 / 血检报告那套模型配置，不另加钥匙 |

知识库在 `app/ai_cs_knowledge/*.md`。改完保存即可，下一句对话会重新读。常见问题和抖音团购两个文件标了「尚未提供」，不要让 AI 现编。

## 怎么用白名单试

1. 先保持 `AI_CS_ENABLED=0`，在公众平台提交 URL，确认能保存。给小程序发一条「在吗」，应出现在微信客服工具里，而不是 AI 回复。
2. 设 `AI_CS_ENABLED=1`，`AI_CS_TEST_OPENIDS` 先写一个占位，例如 `placeholder`，重启。
3. 用自己的微信打开小程序，进「联系客服」发一句「你好」。这条会转给微信客服，同时后台 **系统 → 客服记录**（手机端在「我 → 客服记录」）会出现这个微信标识，原文不会存下来。
4. 把那个标识抄进 `AI_CS_TEST_OPENIDS`，重启。再发「你们体检要空腹吗」。只有这个微信号会收到 AI。别的客户仍然进微信客服工具。
5. 预约试一句「帮我约明天下午东环店皮肤科」。AI 应先列出档案和宠物；有多只就先问是哪只。它报出门店、项目、宠物、日期和时间之后，回复「确认」才会出现一条 `source=ai_cs` 的预约。没回复确认之前，预约表里不该有新记录。
6. 还没绑定档案时，让它预约，应提示去小程序首页用「绑定我的档案」。问体检、疫苗、绝育、美容价格仍可以答。
7. 发「人工」，这条会在当次响应里转给微信客服工具。AI 自己没把握时，会回电话，并在客服记录里留一条转人工，状态是「待通知同事」。同事的服务号模板消息留到第 5 步，现在不发。

价格只来自 `06-beauty-prices.md`。问手术多少钱、抖音套餐里有什么，应该说资料还没有，而不是报一个数。猫三联按猫来说，不要按须知原文里写错的「犬」。

## 回滚

把 `AI_CS_ENABLED=0` 写回 `.env` 并重启。推送地址可以留着：消息继续验签，并转给原来的微信客服，AI 不再回复。

要连地址一起停用，在公众平台的消息推送里关闭。关闭后，客户消息直接进入微信客服工具，不再经过这台服务器。
